# STR Welcome Pages

One shared template, one JSON data file per property, deployed as separate
Netlify sites — all from this single GitHub repo.

## Structure

```
index.html              Shared page shell (don't edit per property)
assets/                 Shared CSS and JS
properties/
  dennis-165-new-boston.json        Content for the Dennis property
  dennis-165-new-boston-hero.png    Its hero photo
build.sh                Builds dist/<slug>/ for every property in properties/
```

`dist/` is generated by `build.sh` and is not committed — Netlify builds it
fresh on every deploy (see below), which is what keeps three sites in sync
with one codebase.

## Deploying a property as a Netlify site

Do this once per property. Because they all pull from the same repo, add
each property in Netlify's UI as its own **site**, pointed at a different
publish folder:

1. Netlify → **Add new site → Import an existing project → GitHub** → pick
   this repo.
2. Set:
   - **Build command:** `bash build.sh`
   - **Publish directory:** `dist/dennis-165-new-boston`
3. Deploy. Netlify runs `build.sh` on every push and republishes that folder.

Repeat with a different **Publish directory** for each additional property
once you add its JSON file — same repo, same build command, new site.

## Adding property #2 or #3

1. Duplicate `properties/example-property.json` as `properties/<slug>.json`
   and fill it in.
2. Drop its hero photo in as `properties/<slug>-hero.<ext>` (jpg/png/webp).
3. Commit and push.
4. In Netlify, add a new site from this same repo with **Publish directory**
   set to `dist/<slug>`.

## Editing existing content

Edit the property's `.json` file, commit, push. Netlify rebuilds and
redeploys that site automatically — no manual rebuild step needed once this
is connected to GitHub.
